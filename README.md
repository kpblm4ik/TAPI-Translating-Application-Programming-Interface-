# 🚀 TAPI — Translating Application Programming Interface

Открытый словарь для перевода интернет-сленга, игрового жаргона и неологизмов в литературную речь и на английский. Подключается к любому сайту **одной строкой**.

## Подключение

```html
<script src="https://kpblm4ik.github.io/TAPI-Translating-Application-Programming-Interface-/tapi.js" defer></script>
```

Скрипт сам найдёт на странице слова из словаря, подчеркнёт их точками, а при наведении (на телефоне при нажатии) покажет перевод.

### Настройки (необязательно)

| Атрибут | Значения | По умолчанию |
|---------|----------|--------------|
| `data-lang` | `literary_ru`, `translation_en` | `literary_ru` |
| `data-mode` | `hover` (подсказка), `replace` (заменить слово), `off` (только API) | `hover` |
| `data-scope` | CSS-селектор области страницы | `body` |
| `data-lookup` | `wiktionary` (перевод выделенного слова), `off` | `off` |
| `data-src` | свой адрес словаря | `v1/all.json` рядом со скриптом |

```html
<script src=".../tapi.js" data-lang="translation_en" data-scope="main" defer></script>
```

Не хотите переводить фрагмент: `<div class="tapi-skip">…</div>` или `translate="no"`.

### JavaScript API

```js
await TAPI.ready;
TAPI.translate('имба');                   // "чрезмерно сильный, ..."
TAPI.translate('имба', 'translation_en'); // "overpowered (OP)"
TAPI.lookup('Нерфнули');                  // вся запись словаря
await TAPI.define('забанили');            // сначала TAPI, затем Викисловарь
TAPI.refresh();                           // перепроверить страницу вручную
```

## Как включить хостинг

1. Репозиторий → **Settings → Pages** → Source: `main`, папка `/ (root)`.
2. Через минуту адрес `https://kpblm4ik.github.io/TAPI-Translating-Application-Programming-Interface-/tapi.js` заработает.
3. Запасной вариант без Pages: `https://cdn.jsdelivr.net/gh/kpblm4ik/TAPI-Translating-Application-Programming-Interface-@main/tapi.js`.


## Любое слово через Викисловарь

С `data-lookup="wiktionary"` читатель может выделить любое слово (двойной клик или долгое нажатие на телефоне) и получить значения из Викисловаря:

```html
<script src=".../tapi.js" data-lookup="wiktionary" defer></script>
```

Как это работает:
- Сначала проверяется `v1/all.json`: там проверенные вручную значения сленга, они главнее.
- Если слова там нет, запрашивается `en.wiktionary.org/api/rest_v1/page/definition/{слово}`. Для словоформы («забаненный») скрипт сам переходит к начальной форме («забанить»).
- Ответы кэшируются в браузере на 7 дней, запросы идут только по действию читателя, а не на каждое слово страницы.
- В подсказке всегда есть ссылка на источник.

**Приватность:** выделенное слово отправляется на серверы Викимедиа из браузера читателя. Режим выключен по умолчанию, включайте его осознанно и упомяните в политике сайта.

**Лицензия:** текст Викисловаря распространяется по CC BY-SA 4.0 (и GFDL). Живые запросы с указанием источника это допускают. Если вы будете копировать его статьи в `all.json`, этот файл тоже придётся распространять под CC BY-SA с указанием авторства.

## Как держать all.json маленьким

- Храните в `all.json` только то, чего нет или что неверно в Викисловаре: свежий сленг, игровой жаргон, ваши термины. Обычные слова берёт Викисловарь по запросу.
- GitHub Pages отдаёт файлы со сжатием, а текстовый JSON сжимается в несколько раз. Несколько тысяч коротких записей остаются небольшим файлом.
- Не добавляйте то, что скрипт и так угадывает: падежи существительных. Нужны только глаголы и необычные формы в `aliases`.
- Если файл всё же вырастет до нескольких мегабайт, делите его по первой букве (`v1/a.json`, `v1/б.json`…) и подгружайте нужные части.

## Эндпоинты

- `/v1/all.json` — словарь.
- `/v1/schema.json` — JSON-схема для проверки.

## Формат слова

```json
"имба": {
  "literary_ru": "чрезмерно сильный ...",
  "translation_en": "overpowered (OP)",
  "category": "gaming",
  "aliases": ["имбовый"],
  "example": "Эта катушка просто имба"
}
```

`aliases` — другие формы слова и фразы (глаголы, «нерфнули» и т. п.). Падежные окончания существительных скрипт отрабатывает сам, а глаголы нужно перечислять в `aliases`. Фразы из нескольких слов тоже можно добавлять ключом («испанский стыд»).

## Как добавить слово

Допишите запись в `v1/all.json` и проверьте файл по `schema.json`. Хорошая запись: объясняет смысл одной фразой, не повторяет само слово и указывает категорию.
